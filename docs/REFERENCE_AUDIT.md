# `references_2026` 사전 조사

## 확인된 기능

- `008.py`: 하드코딩된 천체에 대해 Narrabri와 평창의 시간별 고도를 계산하고 곡선을 표시합니다.
- `007.py`, `009.py`: 전천 RA/Dec 격자를 두 지점의 AltAz로 변환하고, 동시 가시 마스크를 시간구간별 사각형으로 압축하여 CSV/PNG/MP4를 생성합니다.
- 루트 `image.png`: 두 관측지에서 여러 3C 천체의 고도 변화를 비교한 결과 이미지로 보입니다. 정식 자산 여부는 아직 결정하지 않았습니다.

## 기존 의존성

- 계산: NumPy, Astropy
- 연구 시각화: Matplotlib, ImageIO, FFmpeg
- 네트워크가 암시되는 데이터: Astropy IERS 지구 회전 자료

## 제품 코드로 직접 가져오지 않는 이유

- 관측지·천체·시각·출력 경로가 하드코딩되어 있습니다.
- `008.py`는 import만 해도 디렉터리를 만들고 GUI 창을 여는 부작용이 있습니다.
- 전천 계산은 요청당 수백만 좌표-시각 변환을 만들 수 있어 HTTP 요청 경로에 그대로 둘 수 없습니다.
- `products/` 고정 경로는 여러 요청이 동시에 실행될 때 충돌합니다.
- 일부 타입 이름과 주석 인코딩, RA 0°/360° 경계 처리 등은 새 테스트로 검증해야 합니다.

## 새 구현 전 검증할 과학 조건

- 두 위치의 순서를 바꿔도 결과가 같은지
- UTC 및 사용자 로컬 시각 변환
- RA 0°/360°와 극점 경계
- 고도 임계값과 지평선 경계
- IERS 자료가 오래되거나 네트워크가 끊긴 경우의 정확도 정책
- 대기굴절, 관측지 고도, 태양/달 이격각, 황혼을 포함할 범위
- '구간 전체 가시'를 끝점 표본이 아닌 연속 구간으로 정의할지

원본 파일은 수정하지 않고, 검증된 동작만 새 계산 모듈과 회귀 테스트로 옮깁니다.
