# BURSTT LTN·OGW 빔 모델 반영 (2026-11-16)

자료: `references_2026/BURSTT_FoV/BeamViz_SiteBeams_261113_new/`. 원본은 유지하고 `beam_centers.csv`와 `beam_contours.csv`에서 LTN·OGW 행만 `backend/app/data/burstt_fov/`에 복사했다. CSV의 방위각·고도는 이미 각 배열 회전각을 적용한 하늘 좌표이며, 앱은 이를 천정 방위 등거리 투영에 한 번만 사영한다.

| Station | 좌표 (위도, 경도, 타원체고) | 배열 | 명목 대역 | 화면에 쓰는 디지털 빔 |
|---|---|---|---|---|
| LTN | 23.714578419°, 120.824404564°, 882.641 m | 4×16, EW 1.0 m, NS 2.0 m, +0.5° | 300–700 MHz | 64개 모델 할당 셀 |
| OGW-32 | 27.091985700°, 142.216909642°, 261.534 m | 2×16, EW 0.833333 m, NS 1.0 m, −26.9° | 300–700 MHz | 32개 미검증 모델 할당 셀 |

표의 위치는 배열 중심이 아니다. LTN은 GNSS RTK 수신기, OGW는 GCP #2 기준점이다. OGW의 높이 datum은 자료에서도 가정으로 분류된다.

LTN의 EW 빔 번호·400 MHz 기준 간격은 2026-06-17의 PSR B0329+54 펄스 한 건과 일치한다. NS 4개 중심은 2026-07-18 이후 마지막으로 문서화된 `--theta` 목록(−11.3°, −1.68°, 9.57°, 30.95°)을 사용한다. 첫 번째는 태양 지향으로 날짜에 따라 바뀔 수 있으므로 다른 관측일의 운영 상태를 확정하지 않는다. LTN 64개 안테나 위치는 자료의 `antennas.csv`에 DGPS 측정값으로 있지만, 제공 빔 셀은 그 좌표에서 계산한 실측 응답이 아니라 서버 명령·모델에서 정의된 중심의 중간 경계다.

OGW는 2026-08 이후 32개 안테나 구성이 확인되지만, OGW-32의 실제 2차 BFM 명령·빔 개수·활성 마스크·안테나 실측 위치는 확인되지 않았다. 표시하는 16×2 셀은 배열 설정과 BFM 기본값에서 유도한 가설이다. OGW-16에만 문서화된 서쪽 약 18° 기울기는 OGW-32의 빔 중심에 적용하지 않는다. NS 두 셀은 제공 모델에 따라 지평선까지 열린다.

모든 경계는 방향 코사인 배열 좌표에서 이웃 중심의 중간값으로 만든 **빔 번호 할당 셀**이다. 실측 전력·감도·FWHM 윤곽선은 아니다. 화면의 `Inside`도 해당 모델 셀에 들어오고 기하학적 지평선 위에 있다는 뜻이며 실제 검출 가능성을 보증하지 않는다. FUS (256)와 PYC (16)는 기존 자료·모델을 유지한다. FUS2 (512)는 포함하지 않는다. GRN·KMN은 이번 패키지에 빔 자료가 없어 기존 명목 FoV를 유지한다.
